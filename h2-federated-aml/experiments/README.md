# Experiments

`configs/default.yaml` holds the controlled H2 matrix. It runs all six scarcity levels for K=3, the lambda set `0, .01, .05, .1, .5, 1.0` at 10% scarcity, and K=2/3/5 at 10% scarcity, for each configured entry in `seeds`. The default lists five seeds. Each run emits raw measured rows plus `scarcity_summary.csv` (mean and sample standard deviation across seeds) and `paired_significance.csv` (two-sided paired Wilcoxon signed-rank comparisons for Local-only vs FedAvg and FedAvg+Boundary vs FedAvg). Tests use matched seed-level rows at each scarcity level; p < 0.05 is marked significant. No metrics are fabricated. The full configured matrix is expensive; use a small temporary config for smoke testing.

Institution privacy is optional (`privacy.enabled` in the YAML or `--institution-privacy` on the single federated CLI command). Before sharing, each institution's complete model delta is jointly L2-clipped and Gaussian-noised; boundary embedding vectors are row-clipped and Gaussian-noised too. This is institution-level update perturbation, distinct from transaction-level DP: it does not perturb individual transactions or their labels. Simulated boundary node IDs, sample counts used as FedAvg weights, partition metadata, and final evaluation outputs remain visible. Noise is applied per communication round and to boundary payloads; this code does not implement a privacy accountant, calibrated end-to-end epsilon/delta, secure aggregation, encryption, or protection against information in those exposed metadata channels. Do not claim a formal end-to-end DP guarantee or transaction-level privacy from this implementation.
